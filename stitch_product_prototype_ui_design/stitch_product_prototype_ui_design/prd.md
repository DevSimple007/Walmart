## 1. 产品概述

### 1.1 产品定位

「沃尔玛购物」是一款**移动端 H5 电商应用**，面向手机浏览器访问，覆盖「逛店发现 → 搜索选品 → 加购结算 → 订单履约 → 资产与会员管理」的完整自助购物链路。支持**到店自提**与**送货上门**两种履约方式，内置会员等级、积分与优惠券体系。

### 1.2 目标用户

| 用户群 | 特征 | 核心诉求 | 对应功能模块 |
|---|---|---|---|
| 家庭日常采购者 | 高频复购生鲜、日百、粮油，需求明确 | 快速找货、稳定库存、便捷结算 | 分类导航、热门推荐、购物车批量结算、到店自提 |
| 价格敏感用户 | 关注优惠与凑单门槛 | 领券、用券、比价 | 优惠券（满减/折扣/立减）、价格排序、限时特惠 |
| 会员积分用户 | 长期留存、有升级意愿 | 看清权益、攒积分升级 | 会员等级卡、升级进度条、积分余额 |
| 移动碎片化用户 | 通勤、排队等短时购物 | 少输入、快路径 | 搜索历史、立即购买直达下单、登录回跳 |

### 1.3 核心使用场景

1. **逛店发现**：首页轮播运营位、分类宫格、热门推荐 → 进入商品详情。
2. **定向搜索**：搜索历史 / 热门搜索 / 最新上架快速定位，支持价格、最新排序。
3. **加购结算**：详情页「加入购物车」或「立即购买」→ 确认订单（配送方式、地址、优惠券）→ 提交。
4. **订单履约**：订单列表/详情中完成付款、取消、确认收货。
5. **资产与会员管理**：维护地址、查看优惠券与收藏、跟踪等级积分。

### 1.4 核心业务链路

```
浏览商品（首页/分类/搜索）
  → 商品详情
  → [登录校验：未登录跳登录页并回跳]
  → 购物车结算 / 立即购买
  → 确认订单（配送方式/收货信息/送达时间/优惠券/备注）
  → 提交订单（表单校验）
  → 下单成功
  → 订单履约（待付款→待发货→待收货→已完成 / 已取消）
```

## 3. 页面功能需求明细

> 每个页面按「页面概述 / 模块与功能点 / 状态与异常 / 数据接口」描述，直接作为原型设计与开发依据。

### 3.1 首页 `/`

**页面概述**：商品浏览入口页，聚合运营位、分类入口与热门商品。

**模块与功能点**

| 模块 | 功能点 | 说明与交互规则 |
|---|---|---|
| 吸顶搜索栏 | Logo | 点击无跳转（品牌标识） |
| | 搜索框 | 只读态，点击跳转 `/search` |
| | 消息铃铛 | 占位入口（无功能，可预留消息中心跳转） |
| Banner 轮播 | 运营位展示 | 3 张：新品上市/限时特惠/生鲜直达；4 秒自动播放，可手动滑动；渐变背景 + 标签 + 标题/副题 |
| 分类宫格 | 分类入口 | 8–16 个分类（图标+名称）；点击跳转 `/category?categoryId=xx&name=xx` 并自动定位该分类 |
| 热门推荐 | 商品网格 | 双列网格：商品图（1:1）、名称（最多两行截断）、价格；点击跳 `/product/:id`；「查看全部」跳 `/category` |
| 数据兜底 | 分类数据 | 分类接口失败/为空时展示内置默认分类（水果生鲜、牛奶烘焙等） |

**状态与异常**
- 首屏加载：居中 Loading；加载完成前不展示空态。
- 无商品：空态「暂无商品」。

**数据接口**：`GET /customer/product/list`（分页取热门）、`GET /customer/product/category/list`、`GET /homeCategory/customer/list`（首页分类图标）。

### 3.2 分类页 `/category`

**页面概述**：两级分类导航 + 商品列表页，支持从首页/搜索页携带分类参数直达。

**模块与功能点**

| 模块 | 功能点 | 说明与交互规则 |
|---|---|---|
| 吸顶搜索栏 | 搜索入口 | 标题「分类」+ 只读搜索框，点击跳 `/search` |
| 一级分类横向导航 | 分类切换 | 「全部」+ 所有一级分类（parentId=0），可横向滚动；选中项主色下划线高亮 |
| 二级分类侧栏 | 子分类筛选 | 左侧 88px 竖栏列出当前一级分类的子分类；选中项高亮 + 左侧竖条指示；「全部」表示不过滤 |
| 商品列表 | 分页加载 | 右侧双列网格；上拉触底加载下一页（每页 20 条）；切换分类/子分类时重置分页并清空列表 |
| 路由联动 | 参数定位 | 携带 `categoryId` 进入时自动选中对应一级/二级分类并加载商品；路由参数变化时同步刷新 |

**状态与异常**
- 无商品：空态「该分类暂无商品」。
- 列表加载中：展示 loading，不重复触发请求（防并发）。

**数据接口**：`GET /customer/product/category/list`、`GET /customer/product/list?categoryId=&pageNum=&pageSize=`。

### 3.3 搜索页 `/search`

**页面概述**：关键词检索页，提供历史、热门、排序能力。

**模块与功能点**

| 模块 | 功能点 | 说明与交互规则 |
|---|---|---|
| 搜索框 | 输入与触发 | 自动聚焦；回车或点击「搜索」触发；有内容时显示一键清除按钮 |
| 筛选条 | 排序 | 综合（重新请求）/ 价格↑ / 价格↓ / 最新；价格与最新为本地排序 |
| 结果信息 | 数量展示 | 展示「N 个结果」+ 关键词 |
| 搜索历史 | 历史管理 | 本地存储最近 10 条（去重、置顶）；点击标签复搜；一键清空（需确认） |
| 热门搜索 | 快捷搜索 | 标签展示热门商品名，点击直接搜索 |
| 最新上架 | 快捷搜索 | 标签展示最新商品名，点击直接搜索 |
| 结果列表 | 分页加载 | 横排卡片（图、名称两行截断、价格、分类名）；上拉分页每页 20 条 |

**状态与异常**
- 未搜索时：展示历史 + 热门 + 最新上架（无历史时隐藏历史区）。
- 无结果：空态「没有找到相关内容」。
- 搜索接口失败：列表置空并展示空态。

**数据接口**：`GET /customer/product/list?keyword=&pageNum=&pageSize=`、`GET /customer/product/hot`、`GET /customer/product/latest`。

### 3.4 商品详情页 `/product/:id`

**页面概述**：商品信息与购买操作页。

**模块与功能点**

| 模块 | 功能点 | 说明与交互规则 |
|---|---|---|
| 导航栏 | 返回 | 返回上一页 |
| 商品大图 | 主图展示 | 单图，等比 contain 展示 |
| 价格区 | 价格与库存 | 主色大号价格；库存状态文案：缺货 / 仅剩 N 件（<10）/ 库存充足 |
| 信息区 | 名称与分类 | 商品名称 + 分类标签 |
| 商品参数 | 参数明细 | 商品编号、商品分类、库存数量 |
| 商品介绍 | 详情文案 | 无描述时展示占位文案「该商品暂无详细介绍」 |
| 底部操作栏 | 首页入口 | 图标按钮跳 `/` |
| | 购物车入口 | 图标按钮跳 `/cart`，常显购物车件数角标（>99 显示 99+） |

### 3.5 购物车 `/cart`（需登录）

**页面概述**：已登录用户的购物车管理页。

**模块与功能点**

| 模块 | 功能点 | 说明与交互规则 |
|---|---|---|
| 页头 | 标题与件数 | 标题「购物车」+「N 件商品」 |
| 商品卡片 | 勾选 | 单个勾选/取消勾选 |
| | 图片/名称 | 点击图片跳商品详情 |
| | 数量调整 | 步进器，下限 1、上限取商品库存（缺省 99） |
| | 删除 | 删除需弹窗二次确认；成功后 Toast「已删除」 |
| 底部结算栏 | 全选 | 全部勾选/取消；与单项勾选状态联动 |
| | 合计 | 仅计算已勾选商品金额 |
| | 结算 | 无勾选商品时按钮禁用；点击跳 `/order/confirm` |

**状态与异常**
- 空购物车：空态「购物车是空的」+「去逛逛」按钮（回首页）。
- 进入页面：自动拉取服务端购物车数据，默认全部勾选。
- 全局角标：购物车 Tab 与详情页图标显示总件数。

**数据接口**：`GET /customer/cart/list`、`PUT /customer/cart/update`、`DELETE /customer/cart/remove/:productId`、`DELETE /customer/cart/clear`。

### 3.6 登录/注册页 `/login`

**页面概述**：账号认证页，支持登录与注册切换。

**模块与功能点**

| 模块 | 功能点 | 说明与交互规则 |
|---|---|---|
| 品牌区 | Logo 与标语 | 图标 + 「Welcome Back」+ 标语 |
| 模式切换 | 登录/注册 Tab | 注册模式多出「昵称」「确认密码」字段 |
| 表单 | 手机号 | 11 位数字（type=tel） |
| | 密码 | 登录与注册均必填 |
| | 昵称 | 注册必填 |
| | 确认密码 | 注册必填，需与密码一致 |
| 校验规则 | 本地校验 | 手机号/密码必填；手机号必须 11 位；注册两次密码一致；昵称必填；不满足时 Toast 提示 |
| 提交 | 登录/注册 | 按钮 loading 防重复提交；成功 Toast 后按 `redirect` 参数回跳原页面，无则回首页 |

**数据接口**：`POST /customer/auth/login`、`POST /customer/auth/register`。

### 3.7 确认订单页 `/order/confirm`（需登录）

**页面概述**：下单前确认页，含配送方式、地址、优惠券与金额核算。

**模块与功能点**

| 模块 | 功能点 | 说明与交互规则 |
|---|---|---|
| 配送方式 | 到店自提 / 送货上门 | 二选一卡片，选中态高亮；送货上门计 5 元配送费，自提免配送费 |
| 收货信息（送货上门时） | 已存地址选择 | 展示地址列表单选；默认地址自动选中；「使用其他地址」转手动填写 |
| | 手动填写 | 收货人、联系电话、详细地址 |
| | 送达时间 | 点击弹底部日期选择器（最小日期为明天），选择后回填 |
| 商品清单 | 明细展示 | 图片、名称、单价、数量（只读） |
| 备注 | 订单备注 | 选填文本 |
| 优惠券 | 可用券展示 | 展示可用券数量；无可用券显示「暂无可用优惠券」 |
| | 选择弹窗 | 底部弹窗列出可用券 + 「不使用优惠券」选项；券需满足：状态未使用、金额达门槛、在有效期内 |
| 金额核算 | 明细 | 商品金额、配送费、优惠券减免（-¥N）、合计（=商品金额+配送费-优惠券，最低 0） |
| 提交栏 | 提交订单 | 固定底部栏，展示实付金额；按钮 loading 防重复提交 |

**校验规则（提交时）**
- 送货上门：收货地址、联系电话、送达时间任一缺失 → Toast 提示并阻止提交。
- 到店自提：无地址/时间要求。

**状态与异常**
- 无选中商品进入：Toast「请先选择商品」并返回购物车。
- 下单失败：Toast 错误信息，按钮恢复可点。

**数据接口**：`GET /customer/address/list`、`GET /customer/coupon/list`、`POST /customer/order/create`。

## 4. 全局功能规则

### 4.1 登录与权限

| 规则 | 说明 |
|---|---|
| 路由守卫 | 标记 `needLogin` 的页面（购物车、订单相关、地址、优惠券、收藏）未登录时跳 `/login`，并携带 `redirect=当前完整路径` |
| 登录回跳 | 登录/注册成功后按 `redirect` 参数回跳原页面，无参数回首页 |
| 登录态失效 | 接口返回 401 时统一清除 Token 与本地用户信息，Toast「登录已过期，请重新登录」并回登录页 |
| 凭证存储 | Token 存 localStorage（key: shop_token）；用户信息存 user_info |

### 4.2 全局状态规范

| 状态 | 规范 |
|---|---|
| 首屏加载 | 页面级居中 Loading（首页、详情、订单详情、优惠券、收藏等） |
| 列表加载 | 上拉分页加载（分类、搜索、订单列表）；切换条件时重置分页并清空列表 |
| 按钮防重复 | 登录、注册、提交订单、保存地址等提交按钮请求期间置 loading/禁用 |
| 图片占位 | 商品图缺失/加载失败展示内置 SVG 占位图，不出现破图 |
| 接口失败 | 统一 Toast 展示后端 message 或网络错误；详情/订单加载失败提示后返回上一页 |
| 空状态 | 统一「圆形浅灰图标 + 文案 + 可选行动按钮」样式，垂直居中 |

### 4.3 购物车全局状态

- 购物车件数 = 所有商品数量之和，作为 Tab 角标与详情页图标角标来源。
- 角标上限 99，超过显示「99+」。
- 未登录时购物车相关页面不加载数据，角标不展示。

### 4.4 页面缓存与标题

- 首页 / 分类 / 购物车 / 我的 四页 keep-alive 缓存，切换 Tab 保留滚动位置。
- 离开一级页面（跳二级页）时滚动位置复位。
- 每个页面通过路由 meta.title 同步浏览器标签标题。

### 4.5 数据一致性

- 购物车商品库存变化：数量步进器上限以商品当前库存为准。
- 结算金额以确认订单页实时计算为准；提交订单后从购物车移除已购商品（立即购买仅清立即购买数据）。

## 5. 核心业务规则

### 5.1 订单状态机

| 状态码 | 状态名 | 可执行操作 | 状态含义 |
|---|---|---|---|
| 0 | 待付款 | 去付款、取消订单 | 已下单未支付 |
| 1、2 | 待发货 | — | 已付款待发货 |
| 3 | 待收货 | 确认收货 | 已发货待签收 |
| 4 | 已完成 | — | 已确认收货 |
| 5 | 已取消 | — | 订单取消 |

### 5.2 优惠券规则

| 券类型 | 枚举值 | 减免计算 | 展示 |
|---|---|---|---|
| 满减券 | 1 | 订单金额 ≥ 门槛时减固定金额 | 满 N 减 M |
| 折扣券 | 2 | 按折扣比例减免（couponValue 为折扣比例，如 0.15 表示减 15%） | X.X 折 |
| 立减券 | 3 | 直接减固定金额 | 立减 N 元 |

- 可用条件：状态未使用 + 金额达门槛 + 当前时间在有效期内。
- 减免上限：优惠金额不超过商品总金额；合计最低为 0。
- 结算页重新进入时已选优惠券需重新校验可用性。

### 5.3 配送规则

| 规则 | 说明 |
|---|---|
| 配送方式 | 到店自提（免配送费、无需地址）、送货上门（配送费 5 元） |
| 送货上门必填 | 收货地址、联系电话、送达时间（最小日期为明天） |
| 自提 | 当前不选择门店，仅记录配送方式（预留门店选择扩展） |

### 5.4 库存与价格规则

- 详情页缺货（stock=0）：加购/立即购买按钮禁用。
- 库存 < 10：展示「仅剩 N 件」提示。
- 价格展示统一保留两位小数，¥ 前缀。
